# _inbox

Drop unprocessed files here.

- **PDFs** (scanned or born-digital) — say "process the inbox" in Claude Code
  or Codex to OCR + extract + file into `sources/`.
- **Images** — same workflow files them into `media/` with a sidecar.
- **Other** — leave a note and the agent will help categorize.

See `skill/workflows/process-inbox.md` for the full pipeline.

This directory is gitignored except for this README and `.gitkeep`. Your
inboxed scans stay on your machine.
